# Naming Conventions

## Python Variables
- snake_case
- descriptive but concise
- examples: df_clean, monthly_report, revenue_by_region

## Excel Sheets
- Summary
- Charts
- Data
- Breakdown

## Columns
- Use lowercase with underscores
- examples: order_id, order_date, total_revenue

## Files
- Use descriptive names with dates
- examples:
  - revenue_report_2025_01.xlsx
  - sales_summary_q3_2026.xlsx
